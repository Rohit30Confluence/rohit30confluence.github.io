## Selected engineering work

### LogSentinel — Apache Log Analyzer & Attack Detection

Python/FastAPI security tooling for streamed Apache log analysis and rule-based detection of brute force, SQL injection, XSS, and path traversal/LFI. Includes percent-decoding, per-IP historical correlation, REST/WebSocket interfaces, tests, Docker, and GitHub Actions CI.

Repository: https://github.com/Rohit30Confluence/log-analyzer-attack-detection

### NDAP — Network Detection & Analysis Platform

Rust packet-processing platform covering PCAP parsing, Ethernet/IPv4/IPv6/ARP/TCP/UDP decoding, flow tracking, TCP reassembly, and detection rules for port scans, SYN floods, and ARP spoofing.

Repository: https://github.com/Rohit30Confluence/ndap

### SOVEREIGN — Local Multi-Agent AI Orchestration Platform

Local-first multi-agent platform with specialized orchestration, research, code-generation, security-auditing, and memory agents. Uses Python/FastAPI, LangChain, ChromaDB, Docker, and local model runtimes such as LM Studio or Ollama.

Repository: https://github.com/Rohit30Confluence/sovereign

### LogSentinel Approval & Audit

Human-in-the-loop authorization service that records approval actor, reason, and decision state for security-response actions. Designed to fail closed when the authorization service is unavailable.

Repository: https://github.com/Rohit30Confluence/logsentinel-audit-service
